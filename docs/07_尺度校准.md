## 1. 问题定义

### 1.1 单目重建尺度不可观测的数学原因

**投影模型**

```
x̃ = K [R | t] X̃_w ,   x = x̃_1/x̃_3 ,  x̃_2/x̃_3
```

其中 `X̃_w = [X_w, 1]^T`，`[R|t]` 为世界到相机的外参，`K` 为内参。

**尺度不可观测性（Sim(3) 规范自由度）**

取任意 `λ > 0`，构造

```
X̃'_w = λ X̃_w ,   R' = R ,   t' = λ t
```

则

```
K [R' | t'] X̃'_w = K [R | λt] (λ X̃_w) = λ · K [R | t] X̃_w
```

而齐次像点的缩放不改变归一化像素坐标：

```
(λ x̃_1)/(λ x̃_3) = x̃_1/x̃_3 ,   (λ x̃_2)/(λ x̃_3) = x̃_2/x̃_3
```

**结论**：单目图像对重建的约束只到 **7 自由度相似变换**（3 旋转 + 3 平移 + 1 尺度）为止。尺度 `s` 在纯图像观测下**不可观测**——任意 `s` 都给出逐像素完全相同的重投影。

**gauge 自由度的分解**

| 自由度 | 是否可观测 | 被什么固定 |
|---|---|---|
| 全局旋转 `R_g` (3) | 不可观测 | 约定：重建世界系的第一帧主轴对齐（`R_g = I`） |
| 全局平移 `t_g` (3) | 不可观测 | 约定：光心（camera center）位于世界原点 |
| 尺度 `s` (1) | **不可观测** | 只能由**度量参考**固定：参照物、手动输入、硬件深度、IMU 重力先验 |

**对算法的直接后果**

| 后果 | 说明 |
|---|---|
| 三角化的绝对距离无意义 | 所有 `t`、所有点的模长都是 `ru`，只有比值有意义 |
| BA 中的平移与三维点存在尺度耦合 | Hessian 在尺度方向上近似奇异 → 求解器必须固定尺度（本文档 §2.6 的尺度参数化）或加入尺度约束残差 |
| 闭环检测的 Sim(3) 校验 | 闭环时必须允许尺度因子（Sim(3) 而非 SE(3)），否则尺度漂移会被误判为不一致 |
| 深度图三角化得到的点云 | 全部 `ru`，不可直接与真实尺寸比较 |

### 1.2 例外情况：IMU 提供弱尺度先验

本产品的单目分支含 IMU（`core/vio/`），这改变了一点结论：

- 加速度计测量的**比力**包含重力分量。已知 `|g| = 9.80665 m/s²`，因此对加速度计做两次积分得到的**位移具有米制含义**。
- 这意味着在理想条件下，单目 + IMU 的**全局尺度是可观测的**（这是单目 VIO 能输出米制轨迹的原因）。
- 但该可观测量**病态**：
  - 偏置 `b_a` 的一阶误差直接进入位移积分，量级为 `b_a · T²/2`；
  - 重力方向估计误差导致"重力方向投影误差"被误当作水平加速度；
  - 尺度误差与偏置误差在可观测量中**几乎完全混淆**（二者的观测方程秩亏）。
- 工程结论：IMU 尺度先验的相对不确定度为 **5% ~ 10%（典型 8% ~ 10%）**（需实测标定），**不足以作为最终尺度真值**，只作为：
  1. 参照物标定的初值与合理性检查（`|s_ref / s_imu − 1| > 0.3` → 判为可疑并告警）；
  2. 无参照物且用户不手动输入时的**兜底值**，此时 UI 必须显示"尺度未标定（基于 IMU 估计，误差约 ±10%）"。

  > **口径统一**：IMU 尺度不确定度在全套文档中一律表述为 **5% ~ 10%（典型 8% ~ 10%）**；参数 `scale_imu_prior_relative_sigma` 的**默认值为 0.10**（对应 ±10%）；UI 文案统一显示 **"±10%"**。00 文档 §8.7 的实测数据（直线 9.2% / 圆周 6.4% / 8 字 4.8%）落在该区间内。

### 1.3 深度设备的尺度单位与精度，以及为何仍需复核

> **前提澄清（对应 00 文档 §8.1 / §8.2）**：深度传感器的**单位**是米（`d` 以米给出，重建结果天然米制），但这**不等于**深度是**高精度真值**。尺度单位正确与尺度精度足够是两件事，本文严格区分：
> - **单位正确** → 重建结果天然为米制，`s = 1`，无需外部尺度参考；
> - **精度足够** → 曲面几何精度与绝对尺度精度是否达标。这决定深度**能否单独承担尺度真值**。

**各深度源的单位与精度定性**

| 设备 | 深度来源与性质 | 单位是否天然米制 | 绝对精度 | 可否单独作为尺度真值 |
|---|---|---|---|---|
| LiDAR（ARKit `sceneDepth` / `smoothedSceneDepth`） | ARKit 对 LiDAR 深度做融合与平滑后的结果（**不是裸 ToF 飞行时间读数**）。低纹理、低反射面不可靠 | **是**，`d` 以米给出 | **厘米级** | **否**，**不得**单独作为尺度真值。仅可用于 ①尺度锚定 ②TSDF 几何先验 ③低纹理区补全 |
| ToF（Camera2 `DEPTH_OUTPUT`） | 直接测量飞行时间 `t`，距离 `d = c·t/2` | **是** | **2 ~ 8 mm** | **否**。可作 TSDF 主输入，但仍须参照物复核 |
| ARCore Depth API（`ALGO_DEPTH`） | 由运动视差 + IMU + 相机标定联合求解 | **是**（不是任意单位） | **2% ~ 5%**（运动深度，且随距离与纹理变化） | **否**。不得单独作为尺度真值 |

**ARKit `sceneDepth` 的具体限制（复述 00 §8.1）**

| 限制 | 说明 | 工程后果 |
|---|---|---|
| 精度为**厘米级** | `sceneDepth` 是为 AR 遮挡服务的低精度深度，不是测量级深度 | 曲面精度显著低于 MVS（00 §8.8） |
| 低纹理 / 低反射表面不可靠 | 漫反射不足或镜面材质处无有效回波 | 该区域深度缺失或跳变，只能靠 MVS 补全 |
| 非裸飞行时间读数 | ARKit 输出是 LiDAR 深度经融合、平滑与时间对齐后的结果 | 不应把它当作"直接测量飞行时间"来推导精度保证 |
| `ARMeshAnchor` 网格不作为产物 | 面向实时环境理解 | 只作先验，不作扫描产物 |

**ARCore Depth API 的三条使用前提（复述 00 §8.2）**

| 前提 | 说明 | 工程后果 |
|---|---|---|
| **0.5 ~ 5 m 区间最准** | 0 ~ 65 m 范围内"可靠但精度下降" | 桌面物体（约 0.3 ~ 0.5 m）恰在最佳区间；远距离扫描须降权 |
| **需设备产生位移后才可用** | 静止时运动深度无有效输出 | 采集流程必须包含环绕运动，静帧不可用 |
| **低纹理表面深度不精确** | 无可靠匹配时深度不可信 | 低纹理区必须由 MVS 主导，深度仅降权不丢弃 |

**结论**：三条深度源**单位均为米制**，故 `BRANCH_RGBD` 中 `s = 1`（重建本身即米制），无需外部尺度参考。但**没有任何一种深度源可单独承担"绝对精准尺度"这一硬性要求**（00 §4.5.2 尺度来源对照表）。因此在**全机型**上仍强制执行一次"尺度复核"。

**仍然需要复核的六个原因**

| # | 原因 | 机理 | 后果 |
|---|---|---|---|
| 1 | 深度与 RGB 的外参标定误差 | 深度相机与 RGB 相机存在基线 `b`，对齐变换把深度重采样到 RGB 平面时，若 `b` 标错 `Δb`，则视差错位 | 表现为"近处放大 / 远处缩小"的系统性畸变，与尺度误差难以区分 |
| 2 | 边缘飞行像素（flying pixel） | 深度图边缘像素混合了前景与背景 | 物体轮廓处深度系统性偏移 |
| 3 | 多径与镜面反射 | ToF 首个/最强回波被反射路径替代 | 局部深度偏大 |
| 4 | 温漂 | ToF 发射波长随温度漂移，标定系数随之漂移 | 慢速尺度漂移（量级 0.5% ~ 2%/10min，需实测） |
| 5 | 运动深度（ALGO_DEPTH）的绝对偏差 | ARCore 的深度先验以特定尺度锚定，低纹理区与远距区有系统偏差 | 尺度虽米制但有 2% ~ 8% 偏差（需实测） |
| 6 | 单位/量纲转换错误 | 驱动返回的 `uint16` 深度需按 `depthScale` 转换为米，系数取错即 1000 倍误差 | 灾难性错误，必须有硬校验 |

**因此 `BRANCH_RGBD` 仍然强制执行一次"尺度复核"**（§4），其作用是**检测**上述问题，而非重新求解尺度。

### 2.2 几何解算总流程

```
① 图像中检测卡片四边 → 亚像素直线拟合 → 四角交点           §2.3
② 卡片四角单应矩阵 H（度量平面 → 图像）                       §2.4
③ H = K[R|t] 分解 → 卡片位姿（正交化）                        §2.5
④ 卡片角点深度求取（BRANCH_RGBD 用深度图 / BRANCH_MONO 用三角化）§2.6
⑤ 尺度因子 s 闭式解（两个已知尺寸约束）                       §2.7
⑥ 尺度注入（点坐标 + 相机平移统一缩放）                       §2.8
⑦ 多视角联合非线性优化（可选精化）                           §2.9
⑧ 不确定度评估与置信度分级                                    §2.10
```

### 2.3 步骤①：卡片平面检测

#### 2.3.3 角点排序

卡片在图像中可能任意旋转，因此：

1. 取四角点，按质心极角排序得到环形序列 `c1..c4`（CCW）。
2. 计算四条边的长度，两条长边为"宽边"、两条短边为"高边"。
3. 选择起始角点使得**第一条边是长边**：即最终顺序满足 `|c1c2| ≈ |c3c4| > |c2c3| ≈ |c4c1|`。
4. 由于 ID-1/CR-80 卡片在宽高比上接近（1.585），长边判定需在 ±12% 容差内一致，否则判为形状可疑并降置信。

输出约定：`c1` = 长边起点，`c2` = 长边终点，`c3` = `c2` 的短边邻点，`c4` = `c1` 的短边邻点。物理边长对应关系（`W` / `H` 为符号，取值由 `scale_ref_width_mm` / `scale_ref_height_mm` 决定）：

```
abs(L_12) = W   (宽, 由 scale_ref_width_mm 决定)
abs(L_23) = H   (高, 由 scale_ref_height_mm 决定)
abs(L_34) = W ,  abs(L_41) = H
```

> **示例（以 ID-1 为例）**：若 `scale_ref_width_mm` = 85.60 且 `scale_ref_height_mm` = 53.98，则 `W` = 85.60 mm、`H` = 53.98 mm。本产品对身份证实际取 `H` = 54.00 mm（中国二代身份证实际规格，见 §2.1），默认参照物为银行卡 CR-80（`W` = 85.60 mm、`H` = 54.00 mm）。

#### 2.3.4 亚像素直线拟合（关键精度步骤）

**问题**：ISO/IEC 7810 ID-1 圆角半径 `R = 3.18 mm`，CR-80 圆角半径 `R = 3.20 mm`。直接用角点检测（Harris / 角点拟合）会把每个角点向内偏置约

```
Δ ≈ R · (1 − cos 45°) / cos 45°
  = 3.18 mm × (1 − 0.70711) / 0.70711
  = 3.18 mm × 0.41421
  ≈ 1.32 mm          (R = 3.18 mm)
```

相对 85.60 mm 的宽度即 `1.32 / 85.60 = **1.54%**` 的系统性尺度误差 —— 单独一项就超过整个误差预算（目标 0.3% ~ 0.5%）。

**解法**：不用角点，用**四条边的直线拟合 + 相邻直线求交**。

| 步骤 | 内容 | 参数 |
|---|---|---|
| 1 | 对每条边，取边缘图中距初始边段中心线 `w` 内的所有边缘像素 | `calib_edge_band_px` = 6（在降采样图上） |
| 2 | 剔除靠近端点的部分（避开圆角弧） | 每端剔除边缘带长度的 12% | 
| 3 | 对每条边做**总体最小二乘直线拟合**（TLS / 正交回归） | — |
| 4 | 角点 = 相邻两条拟合直线的交点 | — |
| 5 | 交点回投到原图坐标 | — |
| 6 | 记录每条边的 RMS 残差 `σ_line`，作为该角点的不确定度来源 | `calib_max_line_rms_px` = 1.5（超阈则该候选作废） |

**残余误差**：直线拟合消除了一阶圆角偏差，残余二阶误差约 `0.05 mm`（占宽度 0.06%）。该数值**需实测标定**。

#### 2.3.5 几何自洽校验（与单应解耦）

用角点求出的四边形，反投影到度量卡片坐标 `(0,0) (W,0) (W,H) (0,H)`，检查：

| 校验 | 判据 | 失败处置 |
|---|---|---|
| 边长比一致性 | `(abs(L12)+abs(L34)) / (abs(L23)+abs(L41))` 与 `W/H` 的相对偏差 | > 8% → 该候选作废 |
| 对角线一致性 | `abs(L13)` vs `abs(L24)` 相对偏差 | > 6% → 降置信（可能透视剧烈） |
| 四角凸性 | 全部叉积同号 | 违例 → 作废 |
| 面积一致性 | 投影四边形面积 vs 原四边形面积 | 偏差 > 5% → 降置信 |

### 2.4 步骤②：单应矩阵求解（DLT）

#### 2.4.1 归一化（Hartley 归一化，强制）

直接用像素坐标做 DLT 在宽幅图像上条件数极差（可达 1e4 量级），必须归一化：

**对图像点集 `u_k`（k=1..4）**

```
c̄ = (1/N) Σ u_k
u'_k = u_k − c̄
mean_dist = (1/N) Σ ‖u'_k‖
s_u = √2 / mean_dist
ũ_k = s_u · u'_k
```

**对目标点集 `v_k`（度量卡片坐标，单位米）**

```
v̄ = (1/N) Σ v_k
v'_k = v_k − v̄
mean_dist_v = (1/N) Σ ‖v'_k‖
s_v = √2 / mean_dist_v
ṽ_k = s_v · v'_k
```

#### 2.4.2 DLT 方程

对每个对应点 `(ũ_k, ṽ_k)`，令 `h = (h₁ … h₉)^T`，齐次关系 `ṽ_k ~ H̃ ũ_k` 给出两组线性方程：

```
[ x_k  y_k  1   0   0   0  −u_k·x_k  −u_k·y_k  −u_k ] · h = 0
[ 0   0   0  x_k  y_k  1  −v_k·x_k  −v_k·y_k  −v_k ] · h = 0
```

堆叠 `N = 4` 组共 **8×9** 矩阵 `A`，解齐次最小二乘：

```
A h = 0 ,  ‖h‖ = 1
h = 右奇异向量中对应最小奇异值 σ_min 的向量
```

反归一化：

```
H = T_v^{-1} · H̃ · T_u
T_u = [ s_u  0  −s_u·c̄_x ;  0  s_u  −s_u·c̄_y ;  0  0  1 ]
T_v = [ s_v  0  −s_v·v̄_x ;  0  s_v  −s_v·v̄_y ;  0  0  1 ]
```

最后归一化 `H ← H / H_{33}`（若 `H_{33} ≈ 0` 则改用 `H_{22}`）。

#### 2.4.3 病态检测

| 指标 | 阈值 | 处置 |
|---|---|---|
| `σ_min(A) / σ_max(A)` | < 1e-8 → 病态 | 作废（通常因四点近共线） |
| 条件数 `σ_max/σ_min` | > 1e7 → 警告；> 1e9 → 作废 | — |
| 四角近共线性 | 四点在图像中的最小面积三角形面积 < 0.05% × 图像面积 | 作废（`calib_min_config_area_ratio`） |
| DLT 重投影误差（度量平面 → 图像） | RMS > 3.0 px → 警告；> 8.0 px → 作废 | `calib_reproj_rms_max_px` = 8.0 |

> 附带收益：`H` 隐含了卡片的度量长宽比，可作为 §2.3.5 自洽校验的独立证据。

### 2.5 步骤③：从单应推相机位姿

#### 2.5.1 分解

令 `h₁, h₂, h₃` 为 `H` 的三列，`K⁻¹ = [k₁ k₂ k₃]`（`k₁, k₂` 为 `K⁻¹` 的前两列）。

标准模型 `H = λ·K·[r₁ r₂ t]`（`r₁, r₂` 为 `R` 的前两列）给出：

```
λ = 1 / ‖K⁻¹ h₁‖
r₁ = λ · k₁ · h₁
r₂ = λ · k₂ · h₂
t  = λ · k₃ · h₃
```

**尺度因子 λ 的稳健取值**：分别用两列计算

```
λ_a = 1 / ‖K⁻¹ h₁‖ ,   λ_b = 1 / ‖K⁻¹ h₂‖
```

取二者的算术平均，并同时输出二者的相对差：

```
λ = (λ_a + λ_b) / 2
δ_λ = abs(λ_a − λ_b) / λ          (双列一致性指标)
```

`δ_λ > 0.02` → 标记平面位姿低置信（可能因强透视或角点定位不准）。

#### 2.5.2 正交化步骤

直接得到的 `r₁, r₂` 一般不严格正交（噪声所致）。用 QR + 符号修正做正交化：

```
步骤 1：正交化 r₁
        r₁' = r₁ / ‖r₁‖

步骤 2：消去 r₂ 在 r₁' 上的分量
        r₂'' = r₂ − (r₂ · r₁') r₁'
        r₂'  = r₂'' / ‖r₂''‖

步骤 3：右手系补全
        r₃' = r₁' × r₂'        （保证 det(R) = +1）

步骤 4：符号修正
        若 (r₁' × r₂') · r₃' < 0  →  r₂' ← −r₂' , r₃' ← −r₃'

步骤 5：组装
        R = [ r₁'  r₂'  r₃' ]     （列向量）

步骤 6：可选 SVD 精修（推荐）
        M = R = U Σ V^T
        R ← U · diag(1, 1, det(U V^T)) · V^T
```

#### 2.5.3 退化与质量指标

| 指标 | 定义 | 阈值 | 处置 |
|---|---|---|---|
| 正交性残差 | `‖RᵀR − I‖_F` | < 1e-3 正常；> 1e-2 → 警告 | — |
| 行列式 | `det(R)` | 必须 == +1 | 否则翻转 |
| 视线倾角 | `θ = angle(t, R·ẑ)`，ẑ 为卡片法向（`r₃`） | 卡片法向与视线夹角 < 25° → 严重掠射，`δ_λ` 会爆 | 拒用该帧（`calib_min_incidence_deg` = 25） |
| 距离合理性 | `‖t‖` 与场景尺度 | — | — |
| 卡片在图像中的面积 | ≥ 2% 图像面积 | 低于此值角点定位噪声过大 → 拒用 | — |

### 2.6 步骤④：卡片角点的三维深度求取

单应只给出方向（平面位姿），要得到尺度必须有**绝对深度**。三条路径：

| 路径 | 适用分支 | 方法 | 精度 |
|---|---|---|---|
| **P1 深度图直接取值** | `BRANCH_RGBD` | 用 `H⁻¹` 把图像角点反投影到度量卡片平面 → 得到 3D 卡平面坐标系下的点 → 用 §2.5 的位姿变换到相机系 → 得到相机系深度 `Z`。再与深度图在该像素处的观测值 `d_obs` 比较：`Z` 与 `d_obs` 的差即外参/标定误差（可直接给出告警） | LiDAR 厘米级；ToF 毫米级；ALGO_DEPTH 差 |
| **P2 多视角三角化** | `BRANCH_MONO` | 用重建得到的相机位姿 `(R_i, t_i)`（ru）对同一物理角点在 ≥ 2 个视图中的观测做三角化（DLT，线性 + RANSAC 剔除错配），得到角点三维坐标 `X_k`（ru） | 纯 MVS 三角化 `σ_ε ≈ 2.0%`（相对卡片尺寸） |
| **P3 PnP 交叉校验** | 两分支通用 | 用度量卡片四角 + `solvePnP`（IPPE 平面解）解出相机到卡片的度量位姿 `T_metric`（米），与重建中的对应量比较 | 见 §2.7.3 |

**P2 的实现要点**

| 项 | 做法 |
|---|---|
| 角点跨视图关联 | 以图像中的卡片位姿 `H_i` 为依据，把视图 j 的卡片区域投影到视图 i，在重叠区做角点最近邻匹配，匹配距离 < 12 px 且不跨越卡片对角才接受 |
| 三角化 | DLT 齐次解（`A X = 0`，6 方程/点），SVD 取最小奇异向量 |
| 剔除 | 每次三角化用 RANSAC，`reproj_err < 2.0 px`，内点率 < 0.6 则该角点判为不可靠 |
| 最小视角数 | ≥ 3 视角；2 视角可用但不确定度加倍 |
| 视线夹角要求 | 参与三角化的视角之间最大夹角 > 15°，否则深度不可靠 |

### 2.7 步骤⑤：尺度因子 s 的闭式解

#### 2.7.1 模型

重建空间中，卡片四角的相邻边长（ru）为：

```
a₁ = ‖X₂ − X₁‖_ru   a₂ = ‖X₃ − X₂‖_ru   a₃ = ‖X₄ − X₃‖_ru   a₄ = ‖X₁ − X₄‖_ru
```

真实边长（m）：

```
L₁ = L₃ = W/1000 ,   L₂ = L₄ = H/1000
```

尺度约束（对每条边）：

```
s · aₖ = Lₖ ,   k = 1..4
```

#### 2.7.2 闭式解（最小二乘）

目标函数 `F(s) = Σₖ wₖ (s·aₖ − Lₖ)²`，一阶条件：

```
dF/ds = 2 Σₖ wₖ aₖ (s aₖ − Lₖ) = 0
→ s · Σₖ wₖ aₖ² = Σₖ wₖ aₖ Lₖ
```

**闭式解**

```
        s = ( Σₖ wₖ aₖ Lₖ ) / ( Σₖ wₖ aₖ² )
```

当四边权重相等（`wₖ = 1`）且几何理想时，`a₁ = a₃ = a`、`a₂ = a₄ = b`，上式退化为两条约束的合并解：

```
s = ( a·W + b·H ) / ( a² + b² )        （W, H 以米为单位）
```

**两个单约束的独立解（用于一致性交叉验证）**

```
s_W = W / a        （由宽边）
s_H = H / b        （由高边）
```

**一致性判据**

```
ρ = | s_W − s_H | / max(s_W, s_H)
```

| ρ | 结论 |
|---|---|
| ≤ 0.01 | 形状与重建自洽，高置信 |
| 0.01 ~ 0.03 | 降置信（可能是深度噪声或角点误差） |
| > 0.03 | 尺度解算病态（形状不符 / 角点错配 / 透视假设失效）→ 拒用，触发 §5 容错 |

> **为什么两个约束都要用**：单用宽边会忽略透视对高边的压缩；单用高边则受宽边的定位误差主导。两者的组合同时利用了两个方向的基线信息。
>
> **关于长边权重**：在等权最小二乘（`wₖ = 1`）下，长边因 `a²` 权重而对 `s` 的贡献更大（`a·W` 项的量级大于 `b·H`），但长边的绝对误差同时也被放大，两者部分抵消。因此**不能**断言"宽边天然获得更高权重"就等于"宽边更可信"——仍需 `s_W` / `s_H` 独立解做一致性交叉验证（见下方 ρ 判据）：只有当两者的相对差 `ρ` 落在阈值内，才能确认形状与重建自洽。

#### 2.7.3 PnP 交叉校验（独立路径）

用度量卡片四角做 `solvePnP`（IPPE 平面解，`recon_calib` 中实现，走 OpenCV `solvePnPGeneric` + `SOLVEPNP_IPPE`）：

```
T_metric,i : 相机系 → 卡片系（单位：米）
```

与重建中的对应量比较：把 `T_metric,i` 的平移部分与重建中"相机 i 到卡片"的三维位移 `Δ_i`（ru）比较：

```
s_pnp,i = ‖t_metric,i‖ / ‖Δ_i‖_ru
```

`{s_pnp,i}` 与 `s_ref` 的加权均值差异 `> 5%` → 告警 `W_CALIB_MULTIVIEW_INCONSISTENT`。

#### 2.7.4 权重 `wₖ` 的选取

| 权重来源 | 表达式 |
|---|---|
| 角点定位不确定度 | `w_k = 1/σ_k²`，`σ_k` 由该角点相邻两条拟合直线的 RMS 残差与基线角共同估计：`σ_k ≈ (σ_line,i² + σ_line,j²)^0.5 / sin(γ_ij)`，`γ_ij` 为两边的夹角 |
| 边长可靠度 | 参与该边的两条边拟合直线残差大 → 权重下调 |
| 视角数 | 该角点被 N 个视角观测 → `w_k ×= min(N, 5)/5`（多视角更可靠） |

**实现要求**：`σ_k` 不得小于 `1e-6 m`（防止权重爆炸），且总权重 `Σw_k ≥ 1e-6`。

### 2.8 步骤⑥：尺度注入

`s` 求出后，**必须**同时缩放两个量，否则几何不自洽：

| 对象 | 变换 | 说明 |
|---|---|---|
| 三维点 `X_j`（ru） | `X'_j = s · X_j` | MVS 深度图反投影得到的点 |
| 相机平移 `t_i`（ru） | `t'_i = s · t_i` | 外参中的平移分量 |
| 相机旋转 `R_i` | **不变** | 旋转与尺度无关 |
| 内参 `K` | **不变** | 内参以像素为单位，与尺度无关 |
| 深度图 | `d' = s · d` | 若深度是 ru 量纲（纯 MVS 深度无此问题） |
| 图像 | **不变** | — |
| IMU 预积分残差 | 需按 `s` 同步重标定噪声项 | 见 §2.9.3 |

**注入实现顺序（避免半尺度状态）**

```
① 求解 s（此时重建仍为 ru）
② 在 SfM/BA 层固定尺度：把 t_i 与 X_j 的尺度因子设为 s，并锁定后续优化
③ 重跑一次全局 BA（尺度已固定），得到自洽的位姿与点
④ 用重跑后的位姿与点做 MVS → 网格化（此时全流程为米）
```

> **不做**"BA 之后再乘 s"的简单后处理：那会导致 BA 收敛的位姿与乘完 s 的位姿不一致（在 BA 中尺度与平移是耦合的），在弱纹理或短基线序列中误差可观。正确做法是把 `s` 作为已知量注入 BA（§2.9.3），然后重跑。

### 2.9 步骤⑦：多视角联合标定（非线性优化）

#### 2.9.1 优化问题定义

**未知量**

| 参数 | 维度 | 参数化 | 说明 |
|---|---|---|---|
| `s` | 1 | `s = exp(σ)`（保证正性） | 尺度因子（m/ru） |
| 卡片世界位姿 `P_c = (R_c, t_c)` | 6 | `R_c` 用单位四元数（`ceres::Manifold`），`t_c` 在 **ru** 中 | 卡片在重建世界系中的位姿 |
| 相机位姿修正 `δ_i` | 每视图 6（可选） | 旋转向量 + 平移增量 | 仅在 `calib_refine_camera_poses = true` 时启用 |

**观测模型**

卡片角点的度量坐标（米，原点 = `c₁`，x 轴沿宽边，y 轴沿高边）：

```
c₁ = (0, 0, 0) ,  c₂ = (W/1000, 0, 0) ,  c₃ = (W/1000, H/1000, 0) ,  c₄ = (0, H/1000, 0)
```

重建世界系（ru）中的卡片角点：

```
Y_k(s) = R_c · ( c_k / s ) + t_c
```

> 关键点：`c_k / s` 把米制卡片换算成 ru。因为 `t_c` 在 ru 中，卡片在重建中的尺寸自动等于 `真实尺寸/s`，因此**尺度与几何的一致性被结构性地强制**。

视图 `i` 中的预测像素（`R_i, t_i` 为重建相机位姿，ru）：

```
X_{i,k} = R_i · Y_k(s) + t_i
x̂_{i,k} = π(K_i · X_{i,k}) ,   π(u) = (u₁/u₃ , u₂/u₃)
```

#### 2.9.2 代价函数

```
E(s, R_c, t_c, {δ_i}) = Σ_i Σ_k  w_{i,k} · ρ( ‖ r_{i,k}^{rep} ‖²_Σ )
                       + λ_d · Σ_i Σ_k  w^d_{i,k} · ( ŷ_{i,k} − y_{i,k} )²
                       + λ_p · Σ_i ‖ δ_i ‖²_Ω
```

其中：

| 残差 | 定义 | 单位 | 说明 |
|---|---|---|---|
| `r^{rep}_{i,k}` | `x̂_{i,k} − u_{i,k}` | px | **重投影残差**（主项） |
| `ŷ_{i,k}` | 卡片角点在视图 i 中由 §2.6-P1/P2 得到的深度（米） | m | **深度/三维一致性残差**，用于打破平面位姿歧义 |
| `y_{i,k}` | `Y_k(s)` 沿视线方向投影到视图 i 的深度 | m | — |
| `δ_i` | 相机位姿修正 | — | 惩罚项，防止相机位姿被过度扭曲以迁就卡片 |
| `ρ` | Huber 核 | — | 鲁棒核，`δ = 2.0 px` |
| `Σ` | 角点不确定度协方差 | px² | 来自 §2.7.4 的 `σ_k` |

**两类残差的取舍（必须诚实说明相关性）**

| 分支 | 推荐配置 | 理由 |
|---|---|---|
| `BRANCH_MONO` | 仅重投影项 + 深度项（深度来自三角化） | 三角化的角点本身就是从同一批像素观测导出的，重投影项与深度项**统计相关**，同时使用会低估不确定度。故给深度项较小权重 `λ_d = 0.05` |
| `BRANCH_RGBD` | 重投影项 + 深度项（深度来自硬件深度图） | 硬件深度与 RGB 观测**独立**（不同物理量），两项近似独立，可给较大权重 `λ_d = 1.0`；同时深度项直接暴露外参标定误差（§4） |
| 强制打破平面歧义 | 加入深度项（`BRANCH_MONO` 亦必须启用） | **纯重投影无法确定平面目标的深度-尺寸 trade-off**，必须借助三角化得到的绝对深度 |

> **平面位姿歧义（planar pose ambiguity）的显式说明**：单视图下，平面卡片沿视线方向移动并按比例放大，可产生完全相同的重投影。因此仅用重投影残差时，`s` 与卡片深度之间存在一个近似的退化方向。§2.6-P2 的三角化深度正是打断该退化的关键量。**任何只做单应 + 单目深度估计的实现都不能声称得到了可靠尺度。**

#### 2.9.3 与全局 BA 的联合

若 `calib_refine_ba = true`（默认），标定结果作为**尺度先验**注入全局 BA：

在 BA 残差中增加一项，把全局尺度 `s_ba` 拉向标定值 `s_ref`：

```
r_scale = ( s_ba / s_ref − 1 ) / σ_prior ,   σ_prior = calib_scale_prior_sigma（默认 0.02）
```

同时 BA 中所有平移与三维点的量纲处理遵循 §2.8。

**IMU 残差的尺度一致性**：BA 中 IMU 预积分残差以米为单位（重力 `g = 9.80665`）。当尺度从 ru 转为米时，IMU 的位置残差权重不变，但协方差中的 `σ` 需同步按 `s` 缩放，否则预积分项会相对变强/变弱。实现上必须在 BA 初始化前一次性完成 IMU 噪声的尺度换算，不得在优化中途切换。

#### 2.9.4 优化器选择

| 项 | 选择 | 理由 |
|---|---|---|
| 求解器 | **Ceres Solver 2.x**（BSD-3-Clause，已在 `third_party/ceres/`） | 支持 `Manifold`（四元数）、Huber 核、LM + 自适应信赖域；BSD-3-Clause 在白名单内 |
| 线性化 | `DENSE_SCHUR`（Schur 补） | 未知量含每视图位姿修正（块状结构），Schur 补效率最高 |
| 最小化器 | `TRUST_REGION` + `LM` 策略 | 对尺度这种强非线性耦合更鲁棒 |
| 尺度参数化 | `s = exp(σ)` | 避免 `s ≤ 0`；同时避免尺度跨越数量级时雅可比病态 |
| 初值 | `σ = log(s_ref)`，卡片位姿由 §2.5 的单应分解给出 | |
| 收敛 | `function_tolerance = 1e-12`，`max_num_iterations = 50`，`max_solver_time_in_seconds = 30` | |
| 失败处置 | 优化未收敛或残差上升 → **拒绝优化结果，保留闭式解 `s`**，并记录 `W_CALIB_OPT_NOT_CONVERGED` | 闭式解更稳健，优化只做精化 |

**替代方案**：自研 Levenberg–Marquardt 不推荐——Ceres 已在依赖清单内，重写无收益且难以保证数值行为一致。

### 2.10 步骤⑧：不确定度评估与置信度分级

#### 2.10.1 闭式解的不确定度传播

记 `A = Σ w_k a_k²`，`B = Σ w_k a_k L_k`，`s = B/A`。设 `a_k` 的相对误差 `ε_k`（iid，`σ_ε`），角点定位误差通过 `σ_ε` 传入：

```
Var(δB) = σ_ε² · Σ (w_k a_k L_k)²  +  Σ (w_k a_k)² σ_{L,k}²
Var(δA) = 4 σ_ε² · Σ (w_k a_k²)²
```

（`δB = Σ w_k L_k δa_k + Σ w_k a_k δL_k`；`δA = 2Σ w_k a_k δa_k`，`δa_k = a_k ε_k`）

由于 `s = B/A` 相对误差为 `δs/s = δB/B − δA/A`，且两项近似独立：

```
        ┌ σ_ε²·Σ(w_k a_k L_k)² + Σ(w_k a_k)²σ_{L,k}²    4σ_ε²·Σ(w_k a_k²)² ┐
σ_s/s = √ ───────────────────────────────  +  ───────────────────────────
        └              B²                                A²              ┘
```

**各不确定度分量的来源与量级**

| 分量 | 来源 | 典型值（需实测标定） |
|---|---|---|
| `σ_ε`（边长相对误差） | 角点定位 + 深度噪声 + 三角化几何 | LiDAR: 0.5%；ToF: 1.0%；ALGO_DEPTH: 3.0%；纯 MVS 三角化: 2.0% |
| `σ_{L,k}`（卡片制造公差） | ISO 卡片 / 中国二代身份证 | 0.29 mm（占宽 0.34%），**按 ±0.50 mm 均匀分布假设推导（假设待实测确认，见 §2.1 与 §8）** |
| `σ_ε` 离群时的保守上限 | — | 5.0%（用于拒绝判定） |

#### 2.10.2 不确定度到尺度误差的直观传播

单个角点的定位误差 `δu`（px）在深度 `Z`、焦距 `f`（px）下引起的深度相对误差：

```
δZ/Z ≈ δu · Z / f · (1/cos²α)      α 为视线与卡面夹角，掠射时急剧放大
```

代入 `σ_ε` 后即可得到上式的 `σ_ε`。

**关于 `calib_min_incidence_deg = 25` 的设定依据（更正此前不成立的论证）**：

`1/cos²α` 因子随 `α → 0` 单调趋近 1（即掠射角越小，该因子越接近 1），**因此它本身不能用来论证"25° 是合理设定"**。正确的读法是：

| `α` | `1/cos²α` |
|---|---|
| 25° | 1.22 |
| 10° | 1.03 |

也就是说，**夹角过小并非主要误差源** —— 单看定位误差传播这一项，10° 与 25° 的差别只有 1.22 vs 1.03。

真正的主导误差源是**基线过小导致的三角化噪声**：§2.6 的 P2 路径用多视角三角化求角点深度，参与视角之间的基线夹角 `γ` 越小，深度不确定度按 `δZ/Z ∝ 1/γ` 放大。当 `α` 很小时，卡片平面接近视线方向，各视角的观测方向几乎共线，有效基线必然极小，三角化噪声急剧上升。

因此需要**双重约束**：

| 约束 | 作用 | 参数 |
|---|---|---|
| 最小入射角 `α ≥ 25°` | 保证各视角的观测方向不共线，三角化有可用的横向基线 | `calib_min_incidence_deg` = 25（高精度档 30） |
| 最小基线夹角 `γ ≥ 15°` | 直接约束三角化几何条件数 | `calib_triangulate_min_baseline_deg` = 15（高精度档 20） |

两者需**同时**满足，缺一则尺度解算病态。

#### 2.10.3 置信度分级

**两个口径的区分（必须先读）**

本节的 `σ_s` 是**标定模块自身解算出的不确定度**（§2.10.1 的闭式解传播 + §2.9 的优化协方差），只含：卡片尺寸公差、角点定位误差、三角化几何条件。它**不包含**下游 BA 合成、MVS 深度残差等其他误差源。

00 文档 §4.6 的验收线「尺度相对误差 ≤ 1.0%」指的是**端到端**尺度相对误差（含 05 文档 §7.3.3 的 BA 阶段 C 先验合成）。

二者的衔接：**标定模块的 `σ_s` 必须 ≤ 0.5%，端到端合成后才可能 ≤ 1.0%**。因此下表的"高"档阈值按此收紧。

| 等级 | 条件（`σ_s` = 标定模块不确定度） | 端到端预期 | UI 呈现 | 是否允许进入自动流水线 |
|---|---|---|---|---|
| **高** | `σ_s/s ≤ 0.005` 且 `ρ ≤ 0.01` 且 `δ_λ ≤ 0.02` 且 参与视角数 ≥ 3 | ≤ 1.0%（满足 00 §4.6） | 显示"尺度可信（±X%）" | 是 |
| **中** | `σ_s/s ≤ 0.05` | 1% ~ 5%（**可能超出 00 §4.6 的验收线**） | 显示"尺度基本可信（±X%）"，建议用参照物再测一次 | 是（参与 `BRANCH_MONO` 标定），但需在导出报告中标注端到端预期 |
| **低** | `σ_s/s > 0.05` 或 `ρ > 0.03` | > 5%（不可接受） | 显示"尺度不可靠，请手动输入实际尺寸" | 否，需用户手动输入后继续 |
| **失败** | §5 任一致命失败模式 | — | 显示具体原因 + 建议动作 | 否 |

> **为什么"高"档是 0.5% 而不是 2%**：05 文档 §7.3.3 给出的端到端合成为 `σ_s,post = 1/√(1/σ_prior² + 1/σ_s,SfM² + 1/σ_s,IMU²)`。以 `σ_prior` = 0.02（`calib_scale_prior_sigma`）、`σ_s,SfM` = 0.05、`σ_s,IMU` = 0.30（IMU 是弱观测，有效 σ 放大）代入，得 `σ_s,post` ≈ 1.85% —— **仅靠参照物先验无法达到 1.0%**。要达到 1.0%，标定模块自身的 `σ_s` 必须收紧到 0.5% 量级，这要求**多视角联合优化 + 必要时手动输入尺寸**（05 文档 §6.1.4 的结论）。
>
> **诚实声明**：`σ_s/s ≤ 0.005` 是**目标值**，当前实现能否稳定达到需实测验证（见 §8）。若实测达不到，UI 必须按实际 `σ_s` 显示，并按上表降级，不得声称"高置信"。

#### 2.10.4 优化结果的协方差

若 §2.9 的优化成功，用最终雅可比的协方差矩阵给出 `σ_s`：

```
Σ = (Jᵀ W J)⁻¹ ,   σ_s = √(Σ_{σ,σ})
```

同时检查 `Σ` 的条件数：`cond(Jᵀ W J) > 1e12` → 标记病态，放弃优化结果，回到闭式解。

## 3. 手动微调

### 3.1 交互设计

标定结束后，UI 进入"尺度确认"卡片，提供三种手动干预方式：

| 方式 | 用户输入 | 影响对象 | 适用场景 |
|---|---|---|---|
| **M1 修正参照物尺寸** | 参照物的实际宽/高（mm） | 重新代入 §2.7 的闭式解 | 用户手里的卡片不是标准尺寸（学生卡、门禁卡、自定义卡） |
| **M2 输入已知特征长度** | 物体上一个可量测特征的实测长度（mm/cm） | `s = L_measured / L_measured_in_recon` | 无参照物，但知道物体某处尺寸 |
| **M3 微调倍率** | 相对当前 `s` 的百分比调整（±0.1% 步进） | `s ← s · (1 + δ)` | 快速试错（例如放进真实场景比对） |

**M2 的实现细节**：系统必须能自动列出候选特征供用户选择，而不是让用户手输抽象长度。

候选特征由 `scale_manual_source` 枚举选择（枚举值见 08 文档 G9 组），对应的重建内长度 `L_recon` 由系统自动计算：

| `scale_manual_source` | 候选特征 | `L_recon` 计算方式 |
|---|---|---|
| 1 | 卡片宽 | §2.7 的 `a`（ru） |
| 2 | 卡片高 | §2.7 的 `b`（ru） |
| 3 | 重建包围盒最长边 | 重建点云 AABB 的 max 维（ru） |
| 4 | 重建包围盒最短边 | 重建点云 AABB 的 min 维（ru） |
| 5 | 重建包围盒对角线 | AABB 对角线长度（ru） |
| 6 | 重建包围盒体积等效球直径 | `(6V/π)^(1/3)`（ru） |
| 7 | 相对微调（倍率） | 不适用，直接改 `s` |
| 8 | 手动直接输入绝对值 | 用户直接输入 `s`（m/ru），不经特征换算 |

用户选择特征 + 输入实测长度（`scale_manual_value_mm`）→ `s_manual = L_user / L_recon`。UI 必须同时显示 "重建中量得 = 84.7 mm（换算后）" 这类具体数值以便用户核对（数值由当前 `L_recon` 与 `s` 实时算出，不是固定文案）。

**M3 的倍率上限**：`scale_manual_delta_pct` 的合法范围为 [-20, 20]（单次），超出需二次确认并记录。

> **参数对应关系**：M1 → `scale_ref_width_mm` / `scale_ref_height_mm`（需重算闭式解）；M2 → `scale_manual_source` + `scale_manual_value_mm` + `scale_manual_enabled`；M3 → `scale_manual_delta_pct` + `scale_manual_enabled`。三者均写入 `overrides` 表（08 文档 §3.4），切换预设时不被覆盖。

### 3.2 手动输入对下游的影响

| 下游对象 | 受 `s` 影响的方式 |
|---|---|
| 三维点坐标 | 整体线性缩放 |
| 相机平移 | 整体线性缩放 |
| MVS 深度图 | 若为 ru 量纲需缩放；MVS 输出通常已是度量深度（基于位姿），只需确认 |
| 网格化 | 泊松的包围盒随之缩放，`mesh_poisson_depth` 对应的实际分辨率随之变化 → **必须同步复核** §06 文档 §1.3 的分辨率换算 |
| 纹理烘焙 | 不受影响（图像侧无尺度） |
| 导出 | 单位仍是米，数值随之缩放 |

### 3.3 仲裁优先级（硬规则）

**优先级从高到低**

| 序 | 尺度来源 | 适用条件 | 说明 |
|---|---|---|---|
| 1 | **手动输入**（M1/M2/M3） | 用户显式操作 | 最高优先级。覆盖一切自动值。同时保留被覆盖的自动值于 `recon_mesh_info.json` 供对比 |
| 2 | **参照物标定**（`s_ref`） | `BRANCH_MONO`，且置信度 ≥ 中 | 主值 |
| 3 | **硬件深度锚定**（`s_depth`） | `BRANCH_RGBD` | 主值；参照物在此仅做复核（§4） |
| 4 | **IMU 重力先验**（`s_imu`） | `BRANCH_MONO` 且无参照物、用户未输入 | 兜底。必须显示"±10%"警示 |
| 5 | **单位尺度**（`s = 1`） | `BRANCH_RGBD` 且深度通道不可用 | 退化兜底，UI 必须显示"未标定" |

**冲突处理规则（明确定义，不模糊）**

| 场景 | 处置 |
|---|---|
| `BRANCH_MONO`，参照物置信度为低 | **不采用**自动值 → 请求用户手动输入。若用户不输入，落到序 4（IMU 先验）并显示警示 |
| `BRANCH_RGBD`，参照物复核偏差 > 5% | **不修改** `s_depth`（R-PREC-1：深度尺度是物理量，人工参照物精度可能更低）；改为告警 `W_CALIB_DEPTH_SCALE_MISMATCH`，提示用户可手动覆盖 |
| `BRANCH_RGBD`，参照物复核偏差 2% ~ 5% | 告警（黄色），不阻断 |
| 用户手动值与硬件深度尺度差 > 10% | 允许，但强提示"手动值与深度测量差异 XX%，请确认"，记录到导出元数据 |
| 用户手动值与参照物自动值差 > 10% | 允许（用户是最终权威），记录 `manual_override = true` |

> **明确不做的事**：不会因为参照物与深度值不一致就"取平均"。两者的不确定度模型不同（参照物受检测噪声与卡片公差支配，深度受温漂与外参支配），平均会同时污染两者。

### 3.4 手动微调的持久化

- 手动值写入会话参数存档（08 文档 §4），键名 `scale_manual_value_mm` / `scale_manual_source` / `scale_manual_delta_pct` / `scale_manual_enabled`。
- 重新打开会话时，若手动值存在，**优先重放**手动值，并提示"已恢复上次的尺度手动值"（R-PREC-6：不做静默回退，也不静默重算）。
- 用户可一键"清除手动值，回到自动标定"。

## 4. 深度设备的尺度复核

### 4.1 复核目的

`BRANCH_RGBD` 中 `s = 1`（深度自带度量）。复核**不求解尺度**，只**检测尺度层面的故障**：

| 故障 | 后果 | 可检出性 |
|---|---|---|
| 深度单位换算系数错误（1000×） | 整体尺寸错 | 极易检出（包围盒异常） |
| 深度-相机外参标定错误 | 几何错位，常被误判为尺度问题 | 可检出（视差一致性检查） |
| ToF 温漂 | 缓慢尺度漂移 0.5% ~ 2% | 需时间序列比对 |
| ALGO_DEPTH 系统偏差 | 尺度偏差 2% ~ 8% | 需参照物 |
| 飞行像素 | 边缘深度偏移 | 可检出（深度不连续性） |

### 4.2 复核方法 A：参照物反向验证（最直接）

**步骤**

| 步 | 内容 |
|---|---|
| 1 | 用户把参照物（卡片）**平贴在被扫描物体表面**或放在场景中可见处 |
| 2 | 系统检测卡片四角（§2.3 全部算法复用） |
| 3 | 在**深度图**上取卡片区域内的深度值：取卡片四角构成的 ROI（内缩 10%，避开边缘飞行像素） |
| 4 | 计算卡片区域深度统计量：`median(d)`、`IQR(d)` |
| 5 | 由 §2.5 的位姿 + 卡片度量尺寸，预测相机到卡片的距离 `Z_pred`（米） |
| 6 | 计算偏差 `δ = (median(d) − Z_pred) / Z_pred` |

**这实际上检验的是深度尺度与外参的联合正确性**：`δ ≠ 0` 说明"深度值 + 相机-卡片几何"不自洽，来源可能是深度单位、外参、或卡片不在被测平面（不共面）。

| `abs(δ)` | 判定 | 处置 |
|---|---|---|
| ≤ 0.02 | 深度尺度正确 | 通过 |
| 0.02 ~ 0.05 | 可疑 | 告警 `W_CALIB_DEPTH_SCALE_SOFT`，建议重新贴放卡片（不共面是最常见原因） |
| > 0.05 | 异常 | 告警 `W_CALIB_DEPTH_SCALE_MISMATCH`，列出三种可能原因（单位 / 外参 / 卡片不共面），提供"用参照物标定覆盖深度尺度"的显式按钮 |

> **注意**：这个检查**不能**替代 §2.7 的尺度求解，它检验的是"深度自洽性"，不是"重建尺度"。在 `BRANCH_RGBD` 中两者恰好都指向同一个 `s`，因此有用。

### 4.3 复核方法 B：深度 vs MVS 的交叉一致性

在同时存在硬件深度与 MVS 深度的区域：

```
r(x) = ( d_mvs(x) − d_hw(x) ) / d_hw(x)
```

| 统计量 | 阈值 | 含义 |
|---|---|---|
| `median(r)` | `abs(median(r)) > 0.03` → 尺度或外参异常 | 全局尺度/外参偏差 |
| `std(r)` | `> 0.05` → 局部不一致 | 飞行像素 / 多径 / 低纹理区伪深度 |
| `P95(abs(r))` | `> 0.15` → 异常 | 深度质量差 |
| 覆盖率 | 有效匹配像素 < 40% → 深度通道不可信 | 提示降级到纯 MVS |

**跨时间一致性（温漂检测）**：在会话首尾各取一次同一区域的深度中值：

```
drift = |d_end − d_start| / d_start
```

`drift > 0.02` → 告警 `W_CALIB_DEPTH_DRIFT`（ToF 温漂特征）。

### 4.4 复核方法 C：包围盒合理性（必做，硬校验）

| 判据 | 阈值 | 处置 |
|---|---|---|
| 重建包围盒最长边 | > 0.02 m 且 < 50 m | 否则报错 `RECON_ERR_CALIB_SCALE_OUT_OF_RANGE` |
| 重建包围盒最短边 | > 0.0005 m | 否则可能深度单位错误 |
| 与深度图直接测得包围盒的比值 | `abs(ratio − 1) > 0.10` → 异常 | 告警 |
| 最长边 / 最短边 | > 1000 → 疑似单位错误 | 报错 |

### 5.1 失败模式全表

| 编号 | 失败模式 | 判定条件 | 根因 | 回退策略 | 错误/警告码 |
|---|---|---|---|---|---|
| F1 | **卡片未检出** | 无候选通过 §2.3.2 的全部判据；或候选数 = 0 | 光照不足 / 背景杂乱 / 卡片被遮挡 / 图像模糊 | ① 提高对比度重试（直方图均衡 + Canny 阈值重算）② 换用 A4 白纸（边界更明显）③ 提示用户"请将卡片完整放入画面并避免遮挡" ④ 允许用户**手动点选四角**（`calib_manual_corner_pick = true`） | `W_CALIB_CARD_NOT_FOUND` |
| F2 | **卡片被遮挡** | 检出的四边形面积 < 图像面积 2%，或四边中任一条的拟合直线 RMS > 1.5 px 且覆盖率 < 60% | 手指 / 环境物体遮挡 | ① 只用可见的 3 条边 + 已知长宽比约束求解（欠定，需配合深度）② 重试 ③ 手动点选 ④ 提示换位置 | `W_CALIB_CARD_OCCLUDED` |
| F3 | **四角共线 / 构型退化** | 四点最小三角形面积 < 0.05% 图像面积；或 `σ_min(A)/σ_max(A) < 1e-8`；或 `cond > 1e9` | 卡片在图像中被压成一条线（掠射） | ① 拒用该帧 ② 在其他帧中寻找（卡片需在至少 2 帧可用）③ 提示"请正对卡片" | `W_CALIB_DEGENERATE_CONFIG` |
| F4 | **姿态退化（掠射）** | 卡片法向与视线夹角 < 25°；或 `δ_λ > 0.02` | 相机几乎平行于卡片平面 | ① 剔除该帧 ② 需要至少 2 帧非掠射 ③ 提示"请调整角度正对卡片" | `W_CALIB_GRAZING_INCIDENT` |
| F5 | **尺度解算病态** | `ρ = abs(s_W − s_H) / max > 0.03`；或 `σ_s/s > 0.05` | 角点错配 / 深度噪声大 / 卡片不在物体表面导致透视假设失效 / 深度与图像不对齐 | ① 剔除贡献最大的角点后重解（单点剔除法）② 用多视角联合优化替代单帧闭式解 ③ 换用 A4 ④ 手动输入 | `W_CALIB_SCALE_ILL_CONDITIONED` |

| F9 | **深度-图像不共面** | §4.2 的 `abs(δ) > 0.05` 且卡片四角深度不共面（RMS > 5 mm） | 卡片未贴在被测表面 | ① 深度尺度不做修改 ② 提示"请把卡片平贴在物体表面" | `W_CALIB_DEPTH_SCALE_MISMATCH` |
| F10 | **用户取消** | 用户在标定界面取消 | — | 回到 §3.3 仲裁链，落到序 4（IMU）或序 5（单位尺度） | `RECON_ERR_CALIB_CANCELLED` |

### 5.2 回退链（有序，逐级尝试）

```
① 参照物多视角联合标定（最高精度）
        │ 失败（置信度低）
        ▼
② 参照物单帧闭式解（高置信度帧）
        │ 失败
        ▼
③ 参照物单帧 + 手动点选四角
        │ 失败
        ▼
④ IMU 重力先验（±10%，显式警示）
        │ 用户拒绝 / 不可用
        ▼
⑤ 手动输入已知长度（M2）
        │ 用户拒绝
        ▼
⑥ 单位尺度 s = 1 + 显式"未标定"横幅（仅 BRANCH_RGBD 可接受）
```

**按分支的终点（不可混用）**

| 分支 | 允许的最深回退 | 说明 |
|---|---|---|
| `BRANCH_RGBD` | 序 ⑥（单位尺度 `s = 1` + "未标定"横幅） | 深度自带米制，即使复核失败仍有度量意义 |
| **`BRANCH_MONO`** | **序 ④（IMU 先验 ±10% + 显式警示）** | **禁止**落到序 ⑥：单目重建的 `s = 1` 表示"重建单位被当作米"，模型尺寸完全无意义。因此 MONO 分支的回退链终点是序 ④；序 ⑤（手动输入）若用户也拒绝，则流程**中止并报错**，不得静默使用序 ⑥ |

> 该约定与 05 文档 §7.2.2 的仲裁链对齐（05 明确 MONO 分支禁止落到序 5 / 本节序 ⑥）。

**每一次降级都必须**：① 在 UI 上明确显示当前使用的尺度来源与不确定度；② 写入 `recon_mesh_info.json` 的 `scale.source` / `scale.sigma_rel` / `scale.fallback_chain`；③ 不改变 `BRANCH_MONO` / `BRANCH_RGBD` 的算法分支（R-PREC-1：降级不是分支）。

### 5.3 单点剔除法（用于 F5）

若 `ρ` 超阈，按贡献度排序逐个剔除角点并重解：

```
for k in 角点按对 ρ 的敏感度降序:
    用剩余 3 角点 + 第 4 角点由度量长宽比推算 → 重解 s
    若 ρ' ≤ 0.01 且 σ_s'/s' < σ_s/s : 采纳
```

3 角点 + 已知长宽比可唯一确定度量平面四边形（第四角由长宽比与平行关系推出），因此 3 角点仍可解。这是一个**冗余设计**：4 个角点提供 1 个多余约束，用来抵抗单个角点的定位错误。
